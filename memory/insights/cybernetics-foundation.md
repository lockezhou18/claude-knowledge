## Core Finding

Engineering cybernetics IS the right theoretical lens for agentic systems. The compound learning ecosystem independently rediscovered principles formalized 50-80 years ago by Wiener, Ashby, Beer, and Tsien. **Zero papers** in the literature apply classical cybernetics directly to LLM agent design — this is a wide-open research space.

## Key Mappings

| Cybernetic Concept | Our System |
|---|---|
| **Ashby's Ultrastability** (two-level feedback) | LLM = Level 2 explorer; skills/hooks = Level 1 crystals |
| **Requisite Variety** (V(E) >= V(D) - V(R)) | Variety attenuation (briefings, scoring) + amplification (skills, tools) |
| **Good Regulator Theorem** | Eval system must model the agent it evaluates |
| **Beer's VSM S1-S5** | S1=skills, S2=task routing, S3=eval, S3*=audit, S4=research, S5=Principle 0 |
| **Bateson's Learning Levels** | L0=prompts, LI=RLHF, LII=compound learning, LIII=principle change |
| **Tsien's Meta-Synthesis** | Human-AI collaboration for open complex giant systems |
| **Eigenform convergence** | Engineering principles survive recursive self-application |
| **Autopoiesis** | Organizationally closed (principles invariant) but structurally open (skills change) |

## 4 Gaps Identified

1. **S2 underbuilt** — coordination/anti-oscillation between concurrent agents is thin
2. **No formal stability proof** — no Lyapunov function for knowledge scoring
3. **PID gap** — nobody has formalized P/I/D control for agents (research opportunity)
4. **Goodhart's Law** — scoring system needs uncorrelated S3* audit

## Two User Insights Grounded

1. **Probabilistic exploration -> deterministic crystallization** = Ashby's ultrastability + phase transitions. Graduation threshold (use_count>=3, score>=2.0) IS the crystallization temperature.
2. **Everything is feedback, not failure** = Wiener's negative feedback is stabilizing, Bateson's "difference that makes a difference", Shannon information from all outcomes.
