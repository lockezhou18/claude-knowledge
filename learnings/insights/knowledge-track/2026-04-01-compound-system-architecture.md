## Context
Built a complete compound learning system from scratch across two sessions (2026-03-30 to 2026-04-01). The system includes a 6-phase engineering pipeline, 19 skills, 5 hooks, an agent-optimized knowledge base with three-signal scoring, and a tiered skill system.

## Guidance
When building agent productivity systems:
1. Start with principles (Faith of God → Engineering Principles), then process (Pipeline), then tools (Skills)
2. Optimize for the agent as primary consumer — pre-compiled briefing file, manifest-based search, tiered loading
3. Skills should emerge from real friction, not architecture imagination — the best skills came from the user saying "I need to..."
4. Test the system before trusting it — e2e tests caught real bugs (scoring engine, scout crashes, Don't Guess rule)
5. The compound loop (Research → Execute → Compound → feeds next Research) is the core value — each cycle should measurably improve the next

## When to Apply
When designing agent memory/knowledge systems, skill ecosystems, or productivity tooling for AI coding assistants.
