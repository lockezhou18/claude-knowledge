## When querying Espresso HireAccessControlDB, use roleassignmentsv3 NOT roleassignment

**Symptoms:** Queried `openhouse.prod_internal_espresso_hireaccesscontroldb.roleassignment` and found TSEP roles (TSEP_RECRUITER, TSEP_TALENT_ACQUISITION_LEADER) for some seats but not others. Concluded missing role assignments.

**Root Cause:** The `roleassignment` table is a legacy table. The active table is `roleassignmentsv3`. The REST API (`d2://hireRoleAssignments`) reads from V3 via `RoleAssignmentsV3DaoImpl`. Data in the legacy table is stale/incomplete.

**Fix:** Always use the REST API (`d2://hireRoleAssignments?q=assignee&...`) or query `roleassignmentsv3` in Openhouse, never `roleassignment`.

**Prevention:** When querying Espresso tables with version suffixes (V2, V3), always check which version the service actually reads from. The DAO class name tells you: `RoleAssignmentsV3EspressoDaoFactory` → use V3 table.
