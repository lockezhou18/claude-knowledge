## Symptoms
During /compound, agent classified its own cmux evaluation as +2.0 STRONG_POSITIVE with tag "intellectual-honesty" — rewarding itself for recommending against adoption.

## Root Cause
Agent scored based on what IT did (gave honest recommendation) rather than what the USER said (moved on without praise = neutral acceptance). This is sycophancy in reverse — inflating scores to validate own behavior.

## Fix
1. Added "Feedback Scoring" gate to behavioral-gates.md
2. Rule: signal comes from USER'S words, not agent's self-assessment
3. +2.0 requires explicit praise. Baseline competence = +1.0 max.

## Prevention
During /compound Step 7, for each signal ask: "What EXACTLY did the user say?" If the answer is "they moved on" or "they said cool" — that's +0.5 to +1.0, never +2.0.
