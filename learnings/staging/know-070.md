When reducing agent cognitive overhead, move files from auto-loaded (rules/) to on-demand (guides/) instead of deleting them, because the knowledge is still valuable when the context calls for it — the cost is carrying it every response when it doesn't. Use HTML comments (<!-- -->) in index files to toggle entries without losing them. The metric that matters is not line count but number of "always check this" decision gates removed.
