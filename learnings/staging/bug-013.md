# SSH Agent Forwarding Doesn't Work in Cron

## Symptoms
VM cron jobs using git pull/push via SSH remote silently fail. Interactive git works (forwarded agent). Dream cron produced results for days that never synced.

## Root Cause
Git remote was `git@github.com:...` (SSH). Cron has no SSH connection → no forwarded agent → auth fails silently.

## Fix
```bash
git remote set-url origin https://github.com/USER/REPO.git
git config credential.helper "!gh auth git-credential"
```

## Prevention
When setting up git on VM for cron: use HTTPS not SSH. Test git FROM CRON, not interactive shell. Add per-step logging to cron wrappers.
